# Teen Mental Health Dashboard — Excel

An interactive Excel dashboard exploring the relationship between sleep,
stress, anxiety, addiction, and social media usage among teenagers.

## 📊 Project Overview

This project uses Microsoft Excel to analyze teen lifestyle and social media
data and present the findings through an interactive dashboard.

The analysis focuses on:

- Sleep patterns
- Stress levels
- Anxiety levels
- Addiction levels
- Social media usage
- Gender differences
- The relationship between sleep and stress

The goal is to transform raw data into clear and accessible insights using
Excel data analysis and visualization techniques.

## 📁 Dataset

**Social Media Impact on Teen Mental Health**

The dataset contains information about teenagers' social media usage,
sleep patterns, stress levels, and other behavioral factors.

## 🛠️ Tools & Techniques

- Microsoft Excel
- Pivot Tables
- Data Visualization
- Correlation Analysis
- Interactive Dashboard
- Data Analysis

## 🎯 Analysis Questions

The project explores questions such as:

- How is sleep related to stress levels?
- How do sleep patterns differ across categories?
- How do stress, anxiety, and addiction levels vary with sleep?
- Are there noticeable differences between male and female groups?
- How are social media usage patterns related to mental-health indicators?

## 📈 Key Insights

- Lower sleep levels are associated with higher average stress, anxiety,
  and addiction levels in the analyzed data.
- The dataset shows a similar overall pattern across male and female groups,
  although the exact averages vary.
- Sleep and stress show a **moderate negative correlation of approximately
  -0.31**.
- This negative correlation indicates that higher reported sleep is
  associated with lower reported stress in the dataset.
- The relationship is an **association, not evidence that sleep directly
  causes changes in stress levels**.
